# 技术动作慢放 Studio

对自制运动视频做**明确范围内的变速播放**（慢放为主），用于技术动作讲解。
变速由自研内核真实完成：音频走 WSOLA 时间伸缩（尽量保持音高），视频按共同媒体时钟取帧，
**不是**设置浏览器 `playbackRate` 后假定各平台行为一致。

## 图形入口（主要交付）

```bash
npm install
npm start
# 打开 http://localhost:8321
```

界面流程：
1. **源视频**：上传本地视频，或点「生成合成示例视频」（真实生成含帧号色块、脉冲与持续音的测试媒体）。
2. **圈定区间与速度**：在预览上播放并用「设为入点/出点」圈定动作区间，拖动速率滑杆。
3. **生成慢放片段**：按钮调用服务端慢放内核真实渲染；结果区循环播放动作，
   实时显示播放位置（输出时间/输出帧号 → 源时间换算），并展示内核上报的
   **实际采用速率、实际解码速率、WSOLA 固定延迟（已补偿）、音频时钟抖动、视频取帧误差、容器音/视时长差**。

## 支持范围（写清楚，不夸大）

- 速率范围 **[0.25, 2.0]**：超出范围的请求被内核**拒绝**并说明理由，不做静默夹取，
  也不宣称任意倍率无失真。
- 慢放（<1）时每个源帧在输出中重复展示；快进（>1，至 2x）按媒体时钟跳帧。
- WSOLA 在极端拉伸（接近 0.25x）下会把瞬态抹宽、音质下降，属算法固有特性；
  音画两者仍受同一媒体时钟约束，不会因此失步。
- 源视频无音轨时如实标注「无音轨」，**不以静音规避音画同步验证**。

## 架构：三条速率线索分离

| 概念 | 实现 | 说明 |
|---|---|---|
| 播放速率 | `core/mediaclock.js` | 媒体时钟斜率：输出时间 → 源时间的分段线性映射 |
| 实际解码速率 | `core/decoder.js` | 拉取式解码，独立计量 帧/秒；只影响缓冲水位 |
| 输出时钟 | `core/encoder.js` | 输出帧序号 / 输出帧率写入容器 PTS，与墙钟无关 |

- **音频**：`core/wsola.js` 纯 JS WSOLA。合成步长 Hs、分析步长 Ha = Hs × rate，
  相关搜索半径 12ms；多声道联动（混合单声道搜索、各声道共用取粒位置）避免声像漂移。
- **算法延迟**：WSOLA 固定延迟（一个窗长，44.1kHz 下约 23.2ms）被记录并在同步对账中
  **一次性扣除**——它是常量管道延迟，不是随时间累积的失步；扣除后上报的残余为
  每粒偏差的 RMS/最大值（音频抖动）与取帧 PTS 误差（视频）。
- **缓冲协调**：解码缓冲水位随当前分段速率动态调整（速率越快，单位输出时间消耗源帧越多，
  预读窗口越大）；超限 pause、回落 resume，分段切换时由引擎重算。
- **变速**：内核支持区间内分段变速（`segments`），界面暴露单段速率 + 区间圈定。

## 验证（帧号 / 脉冲 / 持续音）

```bash
npm test          # 端到端内核测试（68 项断言）
```

合成媒体自带可机读标记：左上角 16 色块 = 帧号二进制位、脉冲时刻整帧提亮（视觉事件）、
音频 440Hz 持续音 + 每 0.5s 一个 2kHz 脉冲。对 1.0 / 0.5 / 0.25 / 2.0 各速率核对：

- 节目时长（音、视频流分别核对）；
- 输出帧号映射（逐帧读回，误差 ≤1 帧）；
- 脉冲位置 = 源时刻 / 速率（容差随拉伸比缩放，因为 WSOLA 会抹宽瞬态）；
- 音画事件对齐（脉冲 vs 闪光事件中心）；
- 持续音主频仍为 440Hz（FFT 谱峰，音高保持）；
- 分段变速的帧号连续性；超限速率/区间被拒绝。

UI 冒烟测试（需本机可运行 Chromium，环境依赖较多，非默认流程）：

```bash
node test/ui-smoke.js   # 需先 npm i -D playwright && npx playwright install chromium
```

## 辅助 CLI

```bash
node cli/slowmo.js probe <视频文件>
node cli/slowmo.js render <视频文件> --in 1.0 --out 3.0 --rate 0.5 -o out.mp4
node cli/slowmo.js selftest
```

CLI 与界面共用同一慢放内核（`core/engine.js`），仅作辅助；主交付为上述图形播放器。

## 目录

```
core/    慢放内核（媒体时钟、WSOLA、解码缓冲、编码、引擎、校验）
server/  HTTP 服务（上传/渲染任务/结果流，Range 支持）
web/     图形播放器（圈定区间、调速、循环动作与播放位置展示）
cli/     辅助命令行
test/    合成媒体生成、分析工具、内核测试、UI 冒烟测试
```
